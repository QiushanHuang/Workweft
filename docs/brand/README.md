# Harness identity

The H-shaped rails connect a task to an outcome. The teal path represents the
work in between; the amber point marks the owner's decision. Navy and ivory keep
the mark readable on a desktop and at README size.

Generated with the built-in imagegen tool, then resized for application packaging.
Source: `harness-logo.png`. Application assets: `apps/desktop/icons/icon.png` and
`icon.icns`. No third-party brand mark was supplied as a reference.

Prompt: "Create a polished minimalist macOS application icon for Harness Control
Terminal, a local-first workspace connecting tasks, AI executions and human
decisions. A distinctive geometric H formed by two upright rounded rails and a
connecting path with a small warm amber decision node. Deep ink navy squircle
tile, pale ivory rails, restrained teal connection. Flat precise geometric
silhouette, excellent legibility at 32px, generous inset, no letters beyond
abstract H, no words, no gradients or 3D mockup, no extra symbols, centered square
1024x1024 single icon. Transparent outside rounded tile if possible."
