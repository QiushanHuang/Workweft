# Workweft 0.4.0 · 织程

**Workweft 是一款运行在本地的 AI 项目管理工具。**

把项目拆成任务，交给 AI 执行，由你检查成果、掌握进度。

- 全新 Workweft 名称，统一桌面窗口、README、导出文件名和安装包。
- 新 W 形图标结合任务节点与代码括号，体现 Agent 执行和项目管理。
- 中英 README 保持同页切换，操作与架构说明同步更新。
- 原有项目数据位置和导入格式不变，无需搬迁数据库。

下载 `Workweft-v0.4.0-macos-arm64.zip`，解压后打开 `Workweft.app`。
先退出旧版本应用。需要 Python 3.9+；AI 执行需要已登录的 Codex CLI 和 Git。
此包为 Apple Silicon 优化构建，使用本地签名，尚未经过 Apple 公证。

## English

Workweft is an AI project management app that runs on your computer. Plan tasks,
run document or bounded code work, inspect results and keep decisions with the project.

This release unifies the product name and introduces a workflow-node/code-bracket
W icon. Existing project storage and export schemas remain compatible. Close older
versions before launching. Download the Apple Silicon ZIP and open `Workweft.app`.
Python 3.9+, Git and authenticated Codex CLI are needed for the documented execution
workflow. The package is ad-hoc signed, not Apple-notarized.
